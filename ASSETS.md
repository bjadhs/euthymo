# Website assets

- **Little Journal logo:** owner-selected original `output/app-icons/2026-10-04/02-little-journal.png` from the Moodimo workspace. A smiling ivory notebook, green binding, peach background. Used without artistic changes; mechanically resized/encoded as `public/images/little-journal.webp`, `public/icon.png`, and `public/apple-icon.png`. Also used in the social card.
- **Garden:** Moodimo’s existing generated original, `Assets.xcassets/MoodGarden.imageset/garden.png`. Mechanically resized and encoded as `public/images/garden.webp`. Provenance and original prompt are recorded in the native app workspace’s `ARTWORK.md`.
- **Mood faces:** original Moodimo default emotion artwork from `DefaultEmmo{Sad,Worried,Okay,Content,Joyful}.imageset`. Mechanically resized and encoded in `public/images/moods/`. No reference-app artwork or labels were copied.
- **Social image:** original typeset composition assembled for the website, using the selected Little Journal logo. `public/images/social.jpg`, 1200 × 630.
- **Interface previews:** original HTML/CSS illustrations and fictional sample moments. They are labeled as illustrative previews and do not claim to be screenshots of a released app.
- **Decorative illustrations:** simple original CSS/SVG compositions, including the envelope, note, and plant drawings.
- **Icons:** Lucide React, ISC license, installed from the package registry.
- **Fonts:** Fraunces, DM Sans, and Indie Flower via Fontsource packages. SIL Open Font License. Font files are self-hosted with the compiled site; no visitor requests to Google Fonts. Licenses are distributed with the site in `public/licenses/`.

No network image service, user journal content, or competitor artwork is required to render the site.
